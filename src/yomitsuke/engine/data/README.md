# Engine data

- `accents.tsv` is `accents.txt` from [Kanjium](https://github.com/mifunetoshiro/kanjium) by Uros O., unchanged, licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The pitch accent notation was provided by Uros O. through his free database. Kanjium builds on EDICT by the Electronic Dictionary Research and Development Group, used in conformance with the Group's [licence](https://www.edrdg.org/edrdg/licence.html).
- `readings.tsv` is yomitsuke's own list of reading fixes, MIT like the code.
