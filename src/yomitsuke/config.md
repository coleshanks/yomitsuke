**fields**: the fields ticked last time, per note type id. The dialog fills this in; there's no need to edit it.

**redo**: whether "Redo fields that already have readings" starts ticked.

**display_offered**: the last version of the card display yomitsuke offered to put into your note types, so it only asks once per version. Tools > yomitsuke Card Display updates them any time.

Your own reading fixes go in `user_files/my-readings.tsv` in this add-on's folder (Tools > Add-ons > yomitsuke > View Files). One word per line: the word, a tab, the reading, and optionally a tab and a pitch code. They win over everything else and survive updates.
